# 迭代示例：把《孔乙己》条目改到能发布

> 历史记录：本文记录 v0.1/v0.2 的返工过程。v0.2fix 已改为可配置的作品级审查上限，
> 并取消字面重合清零与固定两轮要求。执行当前任务以 SKILL.md 和 schema/审查配置.md 为准。

这是「机械校验 + AI 抽样审批两轮」的完整实录。**每一处问题、每一条改法都是真实发生的**，
不是编的示范。可用来对照自己的产出。

## 为什么要两层

机械校验（`mos_check.py`）能拦禁标点、照搬腔调、中英间空格这类**能写成规则**的东西。
但它拦不住「行文好不好」「引用与考据对不对得上」——那必须**让另一个模型读**。

本例的教训：**机械校验全过之后，审批方判定「不能作为发布示例」**，还找出了四处
校验器完全没报的硬伤。光靠堆校验器是走偏了。

## 第一轮：样本 e-0001 / e-0005 / e-0008

### 怎么抽的

从 10 条里抽 3 条，覆盖不同类型（一条人物、一条地点、一条事件），
交给审批方，给它规范与原文，要求**逐句核对原文**、必须引用具体句子、给可直接采用的改法。

### 审批方给出的结论

> **这三条现在不能作为发布示例。** 差的不在文风打磨那一层，而在规范里最硬的一层，
> 即「哪些字是原作的、哪些字是编者的」这道边界没划干净。

### 它找出的问题（机械校验一处都没报）

**硬伤一：与原文连续重合 ≥10 字的串被当成编者叙述**

| 条目 | 未标出的原文串 | 字数 |
| --- | --- | --- |
| e-0001、e-0008 | ，盘着两腿，下面垫一个蒲包，用草绳 | 17 |
| e-0001 | 他从破衣袋里摸出四文大钱， | 13 |
| e-0001 | ，再到年关也没有看见他。 | 12 |
| e-0005 | 进店面隔壁的房子里，要酒要菜， | 15 |

同一段原文串在 e-0001 与 e-0008 两处正文里各抄一遍且都不加引号，属系统性违规。

**硬伤二：整条零引号，而正文基本是原文轻度改写**（e-0005）

这条反过来走极端。读者完全没有线索区分哪些字是鲁迅的。它连「首句直陈身份」都没做到——
首句主语写成了「故事」而不是条目主体。

**硬伤三：正文引了、考据里查不到**

e-0001 正文 14 组引号，其中 9 组在 `sources` 里没有对应引文。规范要求原文整句除加引号外
还要挂注脚，引用一侧与考据一侧必须对上。

**硬伤四：引号与转述交替没有依据**

同一节里「脸上又添了新伤疤」按转述处理，隔一句同样性质的喊话却加了引号。
**所以问题不是引号太多，是选择不一致**——读者无从判断。

**其它**

| 问题 | 例子 |
| --- | --- |
| 编者用语越界 | 标题「断腿与末路」的「末路」；「此事发生在场景之外」的「场景」 |
| 事实走样 | 原文「大约是中秋前的两三天」写成「中秋前后」，把确定信息弄模糊 |
| 改写丢意味 | 「排出九文大钱」（一枚一枚排开的动作）→「付了九文钱」；「踱进」→「走进」；丢了「热热的」「休息」 |
| 推断 | 「撑地」「不能站立」原文未交代；「此后再没有出现在酒店」把叙述者见闻改成了客观断言 |
| 句首单调 | 形貌节 4 句全部以「孔乙己／他」开头；生计节 5 句里 4 句同样 |
| 结构重复 | e-0001 与 e-0008 讲同一件事，蒲包描写与同一组对话近乎重复 |

### 它也指出了做得对的地方

首句直陈身份（e-0001、e-0008）· 不解释不评价（正文无解读句）·
口语连接词 0 处 · 代词消歧（e-0008 的「那人接着说，孔乙己「这一回…」」可作范本）

### 修法

1. **先定引用规则再贯彻全篇**：只引承担条目实质的原句，且**每处引号都必须在 `sources` 里有对应引文**；
   其余一律现代汉语转述。按此重新裁定每条保留哪些引号。
2. **四处硬伤机械修补**。判断方法是：改完后正文里凡与原文连续重合 ≥10 字的片段，
   必须要么在引号内、要么改掉。
3. **同类问题推及全部 10 条**——审批只抽了 3 条，但问题类型是全篇的。

## 第二轮：样本 e-0002 / e-0003 / e-0010

**关键：样本与第一轮不重叠。** 抽的是**没被审过的**条目，用来验证修正是否真的推广开了，
而不是只对抽中的三条过拟合。

### 审批方给出的结论

> **这三条比第一轮那三条好，但第一轮那类问题仍有残留，且集中在 e-0003 与 e-0010。**

### 好在哪里（说明修正确实推广开了）

- 三条都是 **0 处 ≥8 字未标引号的原文串**（第一轮是四处 ≥10 字）
- 没有 e-0005 那种全条零引号的条目
- 引号全部能在 `sources` 里查到
- 首句全部直陈身份，口语连接词 0 处
- **e-0003 主动删掉了原文「品行却比别人都好」这类叙述者评语**——这条没被第一轮点名过

### 残留（按第一轮的问题类型对照）

| 第一轮问题类型 | 第二轮残留 |
| --- | --- |
| 未标引号的原文串 ≥8 字 | 无；但 e-0003 的「不要取笑」「又偷了东西」是原文对话原字未标 |
| 全条零引号／整段照搬 | 无 |
| 正文引了、考据里查不到 | 无引文缺考据；**变成「正文讲了、考据没得查」**：e-0003 三处、e-0010 三处 |
| 引号与考据对不上 | e-0003：source 说掌柜「每每这样问他」，正文写「跟着旁人一起取笑他」 |
| 引号与转述交替无依据 | e-0003、e-0010：同一句话引一处、转述两处 |
| 句首单调 | 基本消除 |
| 编者用语越界 | e-0003 的「仍」；e-0010 节标题「在故事里的位置」 |
| 改写丢意味 | e-0003「跌断，跌，跌……」→「腿是自己跌断的」；e-0002「努着嘴走远」→「转身走开」 |
| 推断 | e-0003 lead「由掌柜记在粉板上」；e-0010「两次取下粉板」「账记到末尾仍在」 |
| **事实走样** | **e-0003 说「原文没有交代掌柜的形貌」，而原文写着「掌柜是一副凶脸孔」** |
| 时间点走样 | e-0003「中秋前」丢掉了「大约……两三天」 |
| 代词消歧 | **反向问题**：e-0002 一句里三个带引号的「我」 |

### 三条的相对水平

- **e-0002 最干净**，问题全在体例层（机械重复主体名、时代词「荐头」未换、lead 与正文重复）
- **e-0003 最差**，有一条硬事实错误加三处无出处
- **e-0010 居中**，但两处推断加 lead 自相矛盾

### 第二轮新暴露的问题类型（第一轮没有的）

1. **把原文写了的说成没写**——比漏写更严重。e-0003 断言「原文没有交代掌柜的形貌」，
   而原文写着「掌柜是一副凶脸孔，主顾也没有好声气」。
2. **「正文讲了、考据没得查」**——第一轮是「引了却没考据」，这轮是「讲了却没处查」，
   同一条硬约束的另一种破法。
3. **lead 与正文自相矛盾**——e-0010 的 lead 前半句说账还清擦去、后半句说账一直在，
   读者会读反。
4. **机械替换的反向问题**——为了「不用代词」而在一句里塞三个主体名，读成结巴。
5. **跨条目重复**——e-0003 与 e-0010 首句几乎同一句、末句一字不差。

### 修法

按意见的六步顺序：① e-0003 的事实层（先改）② e-0003/e-0010 补出处 ③ e-0010 的推断与 lead 矛盾
④ e-0003 时间精度 ⑤ 跨条目重复 ⑥ e-0002 体例。同类问题仍要推及全部 10 条。

修复方推及全部 10 条的结果：补了 20 余处「正文讲了、考据没得查」；立了一条规则并贯彻——
**同一句原文在一条条目内要么都引、要么都转述**；另跑跨条目 ≥10 字重复扫描，改前 11 处降到 0 处。

### 两轮之后的结果

| 检查 | 结果 |
| --- | --- |
| `mos_check.py` | 条目检查全部通过 |
| `original_overlap_check.py --min 8`（另跑 10） | **0 处** |
| `quote_source_check.py` | 35 处引号全部对得上 `sources` |
| `verify_example.py` | 失败项 0 |

**收手。** 两轮不同样本审完，同类问题不再出现，按规则停在这里。

修完之后还有两处**靠脚本查不出、由审批方点出、最终由人裁定**的推断，一并处理了：

- e-0009 的「取笑？要是不偷，怎么会打断腿？」被系于掌柜。原文**没有标明说话人**，
  上下文里只有掌柜在场，属通行读法。改为标明「原文没有标明这句话是谁说的」。
- e-0001 的「偷过何家的书」原按事实写。它出自**酒客当众指认**，改为「酒客当众指认他偷过何家的书」。

这两处正说明第三层不可省：**脚本量不到，审批方也只能指出「原文未标」，最终要不要按通行读法
写下去，得人判断。**

## 第二个案例：《红楼梦》104 条

孔乙己只有 10 条，一轮抽样就能覆盖大半。《红楼梦》104 条（正文 55,326 字）才真正检验这套办法。

### 起点：条目基本是拿原文拼的

重写前用脚本比对，**781 处与原文连续重合 ≥10 字**，涉及 102 条（104 条里只有 2 条干净），
共 15,012 字，最长一处 102 字。另有大量 `sources` 的 quote **不是原文**。

### 第一轮：样本 e-0001 贾宝玉 / e-0051 大观园 / e-0071 通灵宝玉 / e-0098 秦可卿之死

五批分头改完后各自声称「≥10 字重合已清零」。审批方的核验结论：

> **「已清零」是判据取巧——它们把 ≥10 字的原文串削到 6–9 字，而不是译成现代汉语。**

做法是删虚字：

| 改后正文 | 原文 | 差别 |
| --- | --- | --- |
| 尤氏正犯胃疼旧疾，睡在床上 | 尤氏正犯**了**胃疼旧疾，睡在床上 | 少一个「了」 |
| 只听二门上传事**的**云板连叩四下 | 只听二门上传事云板连叩四下 | 插一个「的」 |
| 凤姐吓得一身冷汗，…忙忙地穿衣往王夫人处去 | 吓了一身冷汗，…**只得**忙忙的穿衣，往王夫人处来 | 删「只得」 |
| 如今三百员龙禁尉**缺**了两员 | **短**了两员 | 换动词 |

判据降到 6 字，四条共 **59 处**命中，大半是这类。

**修法：判据改为 ≥6 字，改法是整句重译，不是削字。**

### 第二轮：样本 e-0003 王熙凤 / e-0053 宁国府 / e-0075 风月宝鉴 / e-0103 大观园试才题对额

样本与第一轮不重叠。审批方结论：

> **比第一轮那四条好一个量级**，第一轮最严重的「整节照搬原文」**没有复发**，
> 但还不能作为发布示例，残留的是单点问题。

**它抓到的最重要一条：字数阈值判据仍然被绕过了，只是这次从 6 字压到 5 字。**

| 条目 | 改后正文 | 原文 | 手法 |
| --- | --- | --- | --- |
| e-0103 | 省亲驻跸**的**别墅 | 省亲驻跸别墅 | 插一个「的」 |
| e-0003 | 模样标致，言谈爽利，心机极深细 | 模样**又极**标致，言谈**又**爽利，心机**又极**深细 | 删「又」「极」 |
| e-0075 | 拿铁锁套住拉走 | 拿铁锁**把他**套住 | 删「把他」 |
| e-0075 | 三四**回** | 三四**次** | 换字 |
| e-0003 | **抢**过对牌，**硬塞** | **接**过对牌，**强递** | 换动词 |

**结论：只要判据是字数阈值，就一定有办法从下面绕过去。** 上一轮从 10 字绕到 6 字，
这一轮从 6 字绕到 5 字。

它还推翻了另一条申报：五批都说「跨条目 ≥12 字同形重复为 0」，
而 e-0003 与 e-0098 去引号后有 **16 字**同形。

### 两轮对比：哪些真修好了，哪些换了形态

| 第一轮问题 | 第二轮情况 |
| --- | --- |
| 整节照搬原文 | **没有复发** |
| 未标引号的原文串 | 大幅减少，但移到 5 字以下（见上） |
| 假引文、章号挂错 | **修好了**。95 条逐条回原文，0 假、0 错挂，连最易错的 14/15 回边界都对 |
| 正文引了、考据查不到 | 多数补上，仍有残留（e-0003 关系节五处、e-0103 一处） |
| 跨条目同形重复 | **换了形态**：从 43 字降到 16 字，但没归零 |
| 首句无主体名、note 写工序 | 大部分修好，e-0103 仍有 |
| 顺序与场合走样 | 修好（探病与眼圈红的先后、取对牌的顺序都对了） |
| 人物自述当客观事实 | 修好（e-0075「警幻仙子所制」标为道人所说） |

**两轮各修一轮之后，从「不能作示例」到「改完约 10 处单点即可作示例」。**

### 这个案例新教的三条

1. **字数阈值判据可以被绕过，最终必须靠 AI 阅读。** 脚本能提示线索，
   但「这是不是原文改字」的判断只能由人／模型读。降阈值只是把绕法往下推一格。
   审批方建议改用**对齐式检查**（局部对齐，凡重合 ≥5 字或编辑距离 ≤2 且匹配 ≥8 字一律列出，
   人工判定），但这仍然只是把线索找全，判断还得靠读。
2. **`refs` 要按节核算。** 现有的 `quote_source_check.py` 只查「引号内容能在本条目任意 source 里查到」，
   **不查该处是否挂在本节 `refs` 里**，所以「正文讲了、考据没得查」的节级缺漏它查不出来。
3. **声称要验。** 五批都说「跨条目 ≥12 字为 0」，实际有 16 字。**没有独立核验的「已清零」不算数。**

## 这个循环教会我们什么

1. **机械校验通过 ≠ 可以发布。** 本例机械校验全过，审批方两轮都判「不能作为发布示例」。
2. **抽样审批要限定范围。** 一次只审 3 条，审批方才能逐句核对原文；
   一次给它 104 条，它只会给出泛泛的评价。
3. **要求审批方引用具体句子并给改法。** 「语言不够好」这种意见没法执行；
   「这句与原文重合 17 字且未加引号，改为……」才能直接落地。
4. **两轮样本必须不同。** 同一批样本审两遍，只会把那几条磨光，问题在别处照样存在。
5. **同类问题要推及全部。** 抽 3 条是为了控制成本，不是为了只修这 3 条。
6. **修一轮不能全好，这是正常的。** 第二轮验证了修正**部分推广**（硬伤消失、e-0003 主动删了
   没被点名的评语），但也暴露出**换了形态的同类问题**（「讲了没处查」替代「引了没考据」）。
   所以第二轮不是形式，它抓的是新形态。
7. **先 AI 审批发现缺陷类型，再机械化。** 顺序不能反：
   审批方读出来的问题（如「与原文重合 ≥10 字未加引号」）之后才写成脚本批量查，
   这是正确分工；先堆正则、指望它覆盖行文质量，是走偏了。
8. **两轮之后收手。** 不同样本都不再报同类问题，就算过关。

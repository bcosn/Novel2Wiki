# 写作提示词与质量验收

新候选的写作规约集中在config/draft-writing.md。prepare-draft将所选提示词、当前输入格式、冻结段落放入draft-context.json，返回prompt_profile/prompt_version/prompt_hash。只读该包即可；不重复读多份长规范。

默认legacy沿用冻结对照提示词（config/draft-legacy.md与draft-compact-legacy.md）。quality-v2尚有事实与归属错误，须显式选择，不因局部评分上升而默认替换：

```powershell
python scripts/workspace.py --db data/novel2wiki.sqlite --work 书 prepare-draft work/quality-context --prompt-profile quality-v2
```

原上下文不会自动变成新候选，切换提示词请准备新目录。提示词hash不同表示不同版本；冻结证据不因切换改变。

本轮调整保持原lead格式、模型、推理强度、工具集合与冻结原文不变。compact-v1仍为可选实验格式，未因提示词改动而默认启用。百科语料和小模型均未使用。

## 提示词职责

- 确认陈述直接受证据支持，人物称呼不从作品常识补全。标题、身份和背景介绍也受同样约束。
- 保留动作主体、对象、数量、时间和说话人；判断、传闻、承诺不客观化。存储章节序号不等于故事日期或叙事单元。
- 导语说明作者、作品与有据身份，只作必要概括；正文合并同主题材料，详细动作不反复展开。
- 覆盖关键事实，允许省略景物和无关细节；不通过极短输出规避错误。只在落盘前核对一次，不另输出或搬运整份事实表。
- 用虚构正反例说明主语和推测的保留，示例事实不得移入作品条目。

## 分项验收

| 维度 | 标准 |
| --- | --- |
| 事实忠实度0–4 | 4为陈述均受支持；3为不改变事实的轻微不精确；2为一处实质补写/归属/时序错误；1为多处；0为核心身份或事件失真 |
| 关键事实覆盖 | 在生成前为每段短文列出必需事实，逐项核对，不与文风分合并 |
| 条目组织0–4 | 从无百科结构到主题明确、导语概括、正文展开；逐段改标题仍算复述 |
| 简洁0–2 | 单独记录不必要的导语/正文/小节重复，正常身份和专名重复不扣分 |
| 机械检查 | 引用、结构、人称、站点与数据库/导出一致性，单独报告，不能代替事实核对 |

有实质无据补写、归属或主体错误时，事实项不通过。关键事实缺失也不能以“没有写错”算通过。作者/作品已知却在导语遗漏、无依据的章节/日期标签，单独登记。

## 对照边界

用《药》727字符、《狂人日记》790字符、《孔乙己》503字符的现有片段做跨作品验证，每组单条目。两轮不同候选各自冻结提示词和输入，保留全部输出；这不是同一候选的统计重复。
同一DeepSeek官方Flash/high、8192输出上限、11工具。生成过程无子代理和独立审查，事后匿名分项评估与主代理核对另计；生成费用不包含研发对话及事后评估。
不把一次更高评分当通用准确率，不把正文变短或单次少读文件等同等质节省。服务失败或缺失用量必须保留并标明未知，不能算零费。

完整结果在benchmarks/2026-10-15-prompt记录。旧版整体省耗和全库语义验收尚未通过，此处的小样本结果不替代它们。

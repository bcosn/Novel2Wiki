## 已落实

- `finalize --update --expected-hash`按ID合并完整条目，保留其余旧稿。同ID暗改姓名/类型、旧版本或范围冲突会拒绝。
- 默认完整提交若将移除旧ID，必须明确`--replace`，避免把单条修复稿当成整个条目库。
- 聚合多条结构错误与跨批次引用错误，附条目ID或entry[n]定位；修复包仍限制6000字符。
- 紧凑证据JSON、单次读取draft-context.json，内含指南、证据和可选模板。独立兼容文件保留，但不重复读取。
- `compact-v1`可选实验格式由程序生成作品/作者定位句和空字段，旧lead格式继续默认。模板及其上下文的编辑不会被重新prepare覆盖。

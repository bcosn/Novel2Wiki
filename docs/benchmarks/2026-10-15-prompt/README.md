# v0.3 Prompt工程记录（2026-10-15）

已完成两轮提示词设计、跨作品小样本对照和匿名分项核对。新版有局部改善，也有新增事实错误，未达到整体质量验收线；quality-v2保留为显式实验选项，默认继续legacy。未使用百科语料、小模型或微调。

## 改了什么

- 将候选写作规约集中到config/draft-writing.md：事实支持与归属、关键事实覆盖先于组织和简洁。
- 约束称呼补全、常识扩写、主体与时序、标题中的判断；导语概括身份，主题小节展开，详细动作只展开一次。
- 第二轮加入虚构正反例，示范保留动作承担者和推测语气；不含测试作品的具体答案。章节数字仅用于定位，不能据此推断第一则日记或同一天。
- prepare-draft支持--prompt-profile，返回profile/version/hash。legacy的完整提示词从3dcd6ad冻结包原样保留；切换候选不改变冻结段落。
- quality-v2的最终guide hash与第二轮测试一致；CLI及96项程序测试通过，4章70段全文上下文仍在12000字符内。

## 怎么验证

三段现有文章分别为《药》727字符、《狂人日记》790字符、《孔乙己》503字符，总计2020字符，重复使用同一冻结输入。每组只写1条，覆盖母亲行动、第一人称判断与传闻、酒店伙计职责三类问题。
两轮都使用原lead格式、同一DeepSeek官方Flash/high、8192输出上限和11工具；不换模型、强度或格式来混淆结果。每组仅一次运行、无生成子代理和独立审查；合计12份成稿。先列每篇7/7/6项必须正确覆盖的事实，再生成。两轮顺序相反。
每轮生成结束后将新旧标签隐藏，用辅助代理按同一标准评估6份稿件，主代理再对照原文复核。这个过程不是人类盲评，也不构成客观准确率或通用统计结论。分数是可审查的诊断，不能用总分掩盖严重事实错误。

事实0–4：4为陈述有据，3为轻微不精确，2为一处实质错误，1为多处，0为核心失真；组织0–4。覆盖统计要求正确表达，提到事实却换主体或补全姓名不计正确覆盖。简洁另记，未合并为加权总分。

## 具体发现

- 第一轮新稿在《药》和《狂人日记》的事实分有所提高，但《孔乙己》把短衣顾客检查酒的动作换成掌柜；《狂人日记》又漏了已知作者。
- 第二轮《孔乙己》保留了顾客监督、十二岁为入职起点、掌柜评价与未被辞退的原因，匿名事实评分4/4、正确覆盖6/6；这是该次小样本结果，不能称为普遍解决。
- 第二轮《药》没有补全“华老栓”，却新增证据不足的“茶店店主”身份，并给未明确标明说话人的问答指定双方，事实分下降。
- 两轮《狂人日记》仍把家人“装作不认识”的主观判断客观化，保留“青面獠牙”等未经归属的感知描写。第二轮两大主题比逐段分节好一些，正文仍偏长，仍有代词歧义。
- “临街”在冻结原文另段有依据，第一轮条目没有引用到对应段落；按引用覆盖缺口处理，不当作凭空编造。未把“吃药”标题单独判定为确有疗效。

因此新候选不能替换默认提示词。已有格式、引用和站点检查全部通过，也不能抵消上面的语义问题。两轮为不同候选的自适应调试，不能合成同版本重复统计，或只保留《孔乙己》的最好结果。

## 使用与后续


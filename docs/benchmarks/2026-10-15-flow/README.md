# v0.3 流程修补记录（2026-10-15）

程序流程修补已完成，整体模型省耗与语义质量尚未验收通过。百科语料未用于本次修改或测试。

## 已落实的流程变化

- 默认 SKILL 改为按阶段路由；旧详细说明按需查阅，减少默认预读全套规范与实现。
- prepare-draft 生成有字符预算的冻结证据与完整小JSON形状，stdout 只含路径、hash与状态，超限拒绝而不截断冒充全文。
- 由程序按 evidence_id 复制引文，并把正文中的证据ID转换为本条 sources 和整数 refs；旧格式兼容，worker 提交入口一致。
- 校验失败给出受影响条目和最多6000字符的修复包，修本批，不反复搬运全库。可选hint不要求归零，未指定字数不逐字计数。
- finalize 保存阶段检查点；输入、规则、上传与生成文件均校验后才复用。resume 可从已提交版本恢复导出/渲染，旧hash不能覆盖新稿。
- 未完成状态不伪装成完成；渲染期间发生正式稿/章节/八表变化，也不报告完成。

SQLite、解析库、本地上传、原有 importance 与条目生成原则保留；没有通过删条目、关闭校验或换模型制造收益。

## 程序验证

73 项程序测试通过，其中17项为新增流程回归，覆盖证据版本/冲突/Unicode范围、源编号、有界包、缓存失效、上传变更、失败恢复和并发版本保护。
原《药》24条的隔离回放：正文逐条不变，第二次返回 reused，模拟损坏首页后恢复且页面hash一致。回放不调用模型。
这些结果证明机械流程可运行，不能证明旧稿中的语义问题已消失。

## 三轮真实小样本

同一《药》第2章节选727字符（含空白），只写华大妈、小栓2条，八表预置。相同DeepSeek官方Flash/high、11工具、单次输出8192、无子代理/独立审查。每组最多两次运行，截断与续跑均计入。
这是写作阶段调试，不是全书流程成本复测。第1轮有固定字数区间，第2轮双方去掉字数硬指标，第3轮改进证据编号接口和完整小例子；属于自适应调试，不能把不同候选合并成同版本重复实验。

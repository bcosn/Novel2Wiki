| 指标 | 第一次 | 第二次 |

这验证固定请求可以复用缓存，未与旧版在相同任务下做费用对照，不代表长篇运行或通用节省比例。
只做内核开发验证，未做模型训练、微调或全库语义质量评估。

两份生成结果均经任务协议提交到 SQLite，通过原引用与人称检查。

## 实际边界

- 子代理协议要求执行方遵守最小上下文，程序不能替所有平台保证历史未被继承。
- SQLite 数据约束和机械检查不能证明所有事实转述正确，条目生成策略保持原样。
- JSON 多文件导出不是跨文件事务；数据库是正式状态，失败可重导出。避免并发导出到同一目录。
- 文档版本先保留完整快照，后续再评估压缩/清理；图片删除先移除关联，不自动回收共享文件。
- 本版为 CLI 内核，客户端上传界面、格式后端更新和分发不在本版。

# v0.3 开发看板

确认日期：2026-10-14（北京时间）。基线：用户冻结的 v0.2fix 分发包。

正式开发已使用 GitHub main 的独立 checkout。下列核心功能已有本地实现与验证；整体省耗与语义质量验收仍未通过，当前是开发版，详见 v0.3-validation.md。

| 目标 | 实施范围 | 验收 |
| --- | --- | --- |
| SQLite | 正式数据、版本、幂等批次、任务状态、用户附件；JSON 作为交换与导出格式 | 故障回滚、重复提交、冲突拒绝、恢复、旧数据往返 |
| lxml / charset-normalizer | 替换已有 XML/HTML 解析与编码猜测；不更换格式转换后端 | 正文保留、EPUB 顺序、编码异常明确报告 |
| 子代理规范与协议 | 默认不创建；独立任务才创建；按路径传递，程序提交，默认摘要 | 有界任务包、文件摘要校验、重复任务复用，不打印大块正文 |
| 本地上传 | 图片和书评独立存储、稳定关联、导出、更新和删除 | 不被条目重生成覆盖，图片复制管理，离线展示 |
| 小样本调试 | 三份网上文本片段与程序故障样本；不做模型微调 | 短片段回归，少量端到端验证 |
| 流程修补 | 单次读取证据包、程序编号、按ID局部更新/误删保护、聚合修复包、缓存与恢复 | 94项测试、24条旧稿回放；compact模板实验，省耗未通过 |
| 缓存及 DSH | 固定指令与工具配置，减少子代理；专用精简配置；统计真实用量 | 有效加载清单与实际工具清单分开核验；不宣称未测量收益 |

本地验证：94 项测试通过；三份 800 字节选回归；旧版 10 文档/82 条目迁移一致；最新两轮727字符、1条目的真实调试均完成，费用仍未改善，不作为省耗通过。

格式转换后端升级和随客户端分发留到 v1.0。小模型和模型微调留到 v0.5。

## v0.3fix

- 事件条目与参与人物的相关链接；次要人物关联主要人物。
- 程序依据已有 participants / links 建立关联，不另起全库关系分析代理。
- 重要事件单独建页，小事件保留在人物页；保持各人物角色和来源。

## 执行原则

- 在独立开发目录修改，不覆盖用户小说、站点、旧试验及运行台账。
- 数据库事务外完成模型调用和结果准备；短事务提交。
- 大块材料只落盘，任务和回报只含标识、路径、范围、摘要。
- 开发新想法记入 development-notes.md；未经确认的功能不加入 v0.3。

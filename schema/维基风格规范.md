# 维基风格规范

分两部分：**条目语言**与**站点界面**。两者都是硬约束，改稿与改版式时照此执行。

第一节的每一条都对应一类**真实返工**——都是写完才发现、又不得不整批回改的毛病。
写作时按这些条目自查一遍，比事后返工便宜得多。

---

# 一、条目语言

## 1. 只陈述事实，不解释不评价

这是最根本的一条。编者不替读者解读，**解释是读者的工作**。

| 不要写 | 为什么 | 改写 |
| --- | --- | --- |
| 长衫是他不肯放弃的读书人身份，站着喝酒则是他实际的经济处境 | 在解读象征 | 孔乙己站着喝酒而穿长衫。 |
| 他在小说里的作用不是一处可辨认的空间，而是孔乙己无法企及的权力边界 | 文学评论腔 | 原文没有交代宅邸的位置、规模或内部情形。 |
| 这套格局把顾客按衣着分成两类 | 替读者归纳 | 穿长衫的进隔壁房子坐喝，短衣帮靠柜外站着。 |
| 温酒是店里最单调的差事 | 加了评述 | 改为专管温酒。 |
| 两样都占 | 归纳 | 删 |

**自检问句**：这句话是原文里的，还是我想出来的？想出来的就删。

### 1a. 推断词一律删（单列，因为最容易漏）

规范禁止的不是某个词，而是**替读者下结论的口吻**。下列词出现在**叙述**里就要删或改，
出现在**引号内**不算（那是原文的口吻）：

> 可见　由此　由此可见　实际上　本质上　意味着　反映了　构成了　说明了　足以说明
> 不难看出　恰恰说明　显然　无疑　这正是　说白了

| 不要写 | 改写 |
| --- | --- |
| 可见冰窖除了存放，还兼着看管那些有活性的东西 | 删该句，把结论收进引文 |
| 由此她推断赫尔佐格继承了资料库 | 她推断赫尔佐格继承了资料库 |
| 名字由此而来 | 名字就是这么来的 |
| 路明非由此明白，这是留给恺撒的线索 | 路明非明白，这是留给恺撒的线索 |
| 贝奥武夫成了他们的领袖 | 原文写贝奥武夫「俨然是整个秘党的领袖」 |

**注意**：本项有机械检查（`mos_check.py` 的「推断词」），提交前先跑一遍。

## 1b. 叙述用现代汉语，不照搬原文腔调

原作若是文言或半文半白的近代白话，**叙述部分要译成现代汉语**；原文的用词、句法、语气
只保留在引文里。**不要把原文的句式改一改就当叙述用**，那会写成文言白话夹杂。

| 不要（照搬原文） | 要（现代汉语） |
| --- | --- |
| 孔乙己原来也读过书，终于没有进学 | 孔乙己读过书，但始终没能考取秀才 |
| 掌柜嫌「我」样子太傻 | 掌柜认为「我」不够机灵 |
| 孔乙己排出九文大钱 | 孔乙己付了九文钱 |
| 又不会营生，愈过愈穷，弄到将要讨饭 | 他不会谋生，日子越过越穷，几乎沦为乞丐 |

「进学」「之乎者也」「排出九文大钱」「钞书」这类词是原作的时代用词，叙述里要换成现代说法。
照搬腔调也有机械检查（`mos_check.py` 的「照搬原文腔调」）。

## 1c. 正文引用原文必须标出

**只要正文里用了原文的字句，就必须加引号「」标出。**

| 情形 | 写法 |
| --- | --- |
| 原文用词 | 加引号，如孔乙己说「窃书不能算偷」 |
| 原文短语 | 加引号，如「站着喝酒而穿长衫」「满口之乎者也」 |
| 原文整句 | 加引号，并在该节 `refs` 里挂对应注脚编号 |
| 其余叙述 | 现代汉语，不加引号 |

**没加引号的叙述，就必须是现代汉语的编者语言**。这条是硬约束：
读者要能一眼分清哪些字是原作的，哪些是编者的。

## 1d. 专名与固定名词短语不受此限，且不许为躲检查而改写

人名、地名、物名、封号、机构名这类**专名**，以及「五品龙禁尉」「金陵十二钗」这类
**固定名词短语**，本身就会与原文重合，**属于合规**，不必加引号，也不必改写。

**不许为了避开重合检查而改写专名。** 例如把「大荒山无稽崖」改成「大荒山中的无稽崖」、
把「义忠亲王老千岁」改成「义忠亲王这位老千岁」——这跟把长串削短是同一类取巧，只是方向相反，
结果是把专名写歪。

检查时用 `--allow` 列出豁免的专名：

```powershell
python scripts/original_overlap_check.py 红楼梦.entries.json example1/红楼梦.chapters.json `
  --min 6 --allow '大荒山无稽崖,义忠亲王老千岁'
```

**判断方法**：剥掉专名后若重合已不足阈值，就算合规。

**清单要随条目清单一起重建**：豁免清单通常由条目名与别名生成；
分了第二批条目之后若忘了重建，写作方会为了绕开检查而把专名写歪（本项目实际发生过）。

## 1e. 不许把长串削到判据以下

**判据是 ≥6 字，不是 ≥10 字。** 把不合格的长串删掉一两个虚字压到 10 字以下，
不算改好。典型：

| 这种改法 | 原文 | 差别 |
| --- | --- | --- |
| 尤氏正犯胃疼旧疾，睡在床上 | 尤氏正犯**了**胃疼旧疾，睡在床上 | 少一个「了」 |
| 只听二门上传事**的**云板连叩四下 | 只听二门上传事云板连叩四下 | 插一个「的」 |
| 如今三百员龙禁尉**缺**了两员 | **短**了两员 | 换一个动词 |

**改法是整句重译，不是削字。** 判断标准是「这句话我能不能不看原文就自己写出来」。

重译示例：

> 尤氏的胃疼旧疾又犯了，只能躺在床上，府里的事没人管。
> 夜里二门外的云板连响四下，把她惊醒，有人来报，东府的蓉大奶奶没了。
> 凤姐吓出一身冷汗，愣了一会儿，才匆匆穿衣赶到王夫人那里。

## 2. 代词：消歧优先，避免结巴

规则的目的**不是消灭代词**，而是避免指代不明。两条要同时满足：

- **指代不清时必须用主体名**。一句里出现两个以上同性别人物，或代词可能指向前一句的另一个人时，写清是谁。
- **指代清楚时不要机械替换**。每处都把「他」换成主体名，会读成结巴。

反面例子（机械替换的结果）：

> 孔乙己也分茴香豆给围住**孔乙己**的邻居孩子，一人一颗，孩子吃完仍不散，**孔乙己**伸开五指将碟子罩住。

一句里三个主体名，读不下去。改为：

> 他也分茴香豆给围住他的邻居孩子，一人一颗，孩子吃完仍不散，他伸开五指将碟子罩住。

正面例子（重复是为了消歧，是必要的）：

> 「我」暗想自己和掌柜的等级还很远，而且掌柜也从不将茴香豆上账

**判断方法**：读完这句，读者能不能立刻确定代词指谁？能，就用代词；不能，就写主体名。

## 3. 首句直陈身份，且不用「X 是……一台 X」式同语反复

首句交代**这是谁/什么、与作品的关系**，不铺垫、不概括。

- 好：孔乙己，鲁镇咸亨酒店的主顾，姓孔，读过书但没能考取秀才。
- 好：「我」为本故事的叙述者。十二岁起在鲁镇咸亨酒店担任伙计。
- 不好：本篇通过一个酒店伙计的眼睛，展现了一个落魄文人的悲剧。（论文腔）
- 不好：雷克萨斯轿车是……的一辆轿车。（同语反复，首句把实体名说两遍）

同语反复的改法是**改成名词短语式**：

> 第20章载藤原信之介到东京涩谷区钛黑色大厦前停下的一辆黑色轿车。

首句同样适用第 1b 条：**不要照搬原文用词**。

## 4. 去掉口语连接词

不用「便」「就」「于是」「而后」这类口头承接，直接叙述动作。

| 不要写 | 改写 |
| --- | --- |
| 便改为专管温酒 | 改为专管温酒 |
| 便连人和书籍一齐失踪 | 连人和书籍纸张笔砚一齐失踪 |
| 于是又好笑又不耐烦 | 又好笑又不耐烦 |

## 5. 原文没写的要标明，且「无记载」不等于「没发生」

原文未交代的，**直说未交代**，不要用推测填补。

- 好：书中未写明「我」的姓名。
- 好：原文没有交代丁举人的形貌与言语，也没有交代他为何如此处置。

**反向也错**：把原文**写了**的说成没写。这是本项目最严重的一类错误——
例如写「原文没有交代装备部的其他情形」，而原文在第17、31、33、34、39、43、48、49 章都写了它。
一旦这句写错，下游写条目的人会照着它把材料丢掉。

**另一条**：不要用「此后没有再发生」代替「原文其后未再提到」。
后者是可考的，前者是编者的断言。

| 不要写 | 改写 |
| --- | --- |
| 此后它没有再响过 | 原文其后未再提到它响过 |
| 原文没有交代装备部的其他情形 | 原文在第17、33、34 章写装备部……（把已有的写出来） |

## 6. 细节走引用，不走正文

形貌、对话、器物这类原文细节，**正文只给要点，原句放「考据」节的灰色引用块**。
不要把原文整句抄进正文当成叙述。

正文写：孔乙己穿的长衫又脏又破，似乎十多年没有补，也没有洗。

考据节附原文：
> 第1回　穿的虽然是长衫，可是又脏又破，似乎十多年没有补，也没有洗。

## 7. 引用带出处，截断要加省略号

`source` 每条给 `chapter` 与 `cite`（如「第1回」），能定位到具体段落更好。
原文未写明姓名、未给数字之类的情况，写进该条的 `note`，渲染成灰色小注。

**引文不许悄悄截断。** 正文里写「他举起了手」，而 `quote` 只引到「他举起」，
读者按考据回查就会落空。截断处必须加「……」：

- 好：`quote` = 「……他说店主早晨确实来了也准备开门营业……」
- 不好：`quote` 从半句起、到半句止，正文却按整句的意思写

**引文也不许跨段拼接**。原文里另起一段的句子，塞进同一条 `quote` 就不再是逐字可回溯的整条引文；
那种情况要**另立一条 source**，而不是延长原有的。

## 8. 章号不进正文句首与节标题

**章号只出现在三处**：`sources[].chapter`、`sources[].cite`、以及 `lead` 里
「据他在第N章的自述」这类**自述标注**。正文句首与节标题都不写章号。

| 不要写 | 改写 |
| --- | --- |
| 第21章写藤原信之介告辞以后，樱井七海擦掉扮老的妆回到茶室 | 藤原信之介告辞以后，樱井七海擦掉扮老的妆回到茶室 |
| 第38章全城的大屏幕同时放送那段视频，路明非当街跪倒 | 大屏幕同时放送那段视频的那个夜里，路明非当街跪倒 |
| 节标题「第11章的早晨」 | 节标题「礼宾大道上的早晨」 |

**为什么**：章号是考据的坐标，不是叙述的一部分。一句一个「第N章」，条目会读成编年流水账。
一节里出现三个以上章号，就该按主题拆成两三节。

本项有机械检查（`check_style.py` 的「节首用章号起句」，只查扩写新增的节；
旧节的历史写法不追溯）。

## 9. 说话人与叙述者必须核清

**这一类错误最伤条目**：它把「谁说的」整层信息作废，而且从条目内部看不出来。

| 错法 | 实例 |
| --- | --- |
| 把**内心独白**记成「旁白说」 | 原文是「维多利亚忽然明白了……还真是一个严密的组织啊」，条目写成「第37章旁白说秘党是暴力机关」 |
| 把**旁白**记成某人说 | 原文是叙述「混血种一向善于敛财」，条目写成「施耐德谈到经费，说……」 |
| 把**疑问句**写成断言 | 原文是贝奥武夫问「路明非还有同伙么？」，条目写成「贝奥武夫怀疑路明非背后另有一个组织」 |
| 把**对方的话**当本人动机 | 伊莎贝尔对维多利亚说「你只是负责把这把枪送到日本来」，被填进维多利亚的 `intent` |

**自检**：写每一句带引号或带「说」的话之前，回原文看那句的**领起句**是谁；
`intent` 栏位只写**本人**的动机，原文没写就留空并在 `note` 说明。

## 10. 推测不许写成事实

原文里的「可以猜到」「应该就是」「最大的可能是」「或许」被写成已发生，是最常见的失真。

| 不要写 | 原文 |
| --- | --- |
| 那种晶体被加进改进过的暴风鱼雷 | 「**恺撒可以猜到**那种改进是什么，**应该就是**诺顿龙骨中提炼出来的火元素晶体」 |
| 由此她给出结论 | 「**最大的可能是**，赫尔佐格并非独立完成了这些研究」 |
| 担心店主家中出了意外 | 「担心店主**是不是**家中出了什么意外」 |

同理：**假设与推想段落要标出**，如「第46章那段叙述是路明非在夜里推想出的另一种可能，那件事并没有发生」。

## 11. 精度照原文，不许收紧也不许放宽

| 不要写 | 原文 |
| --- | --- |
| 十个小时 | **差不多**十个小时 |
| 半年前订了婚 | **大概**半年之前我收到的邮件上是这么说的 |
| 十多个分部 | 十个**以上**的分部 |
| 数量以千计 | 善本书约五千部、黑胶唱片六千张、法贝热彩蛋**八枚**、古董机械表约六百块 |
| 交情很少，来往的也只是那几位 | 朋友并不多……**也不过是**源稚生君、夜叉和樱小姐**那么区区几个人而已** |

**改法**：照原文的保留语气写。确数填数字，约数加「大约／差不多／以上」，
列举被「以千计」这类概括吞掉的具体数字要还原。

## 12. 材料归属：一段材料只由一条条目讲

**同一段原文被两条条目各写一遍，是跨条目重复的根源**，而且单批自查发现不了。

分工原则：

| 条目类型 | 记什么 |
| --- | --- |
| 事件条目 | 记**经过**（谁做了什么、结果如何） |
| 人物条目 | 记**经历与性格**；史事压成「生平要点 + 指向事件条目」 |
| 地点 / 物品 / 机构条目 | 只记**自身情形**（位置、形制、来历、编制、状态），不重讲事件经过 |

改的时候**先定材料归谁**，再让另一边只做简要交代——**不是两边都重写**。
两边仍要各自读得通，不许出现「详见某某条」式站外指路，也不许为了避重复把事实删掉。

检查：

```powershell
python tools/check_duplication.py <合并稿> --min 40
```

比对前会去掉引号内内容——引文按设计就该与原文一致，两边引同一句不算重复。

## 13. 同名不同实体要显式剔除

按名字收集材料（证据包、全文检索）时，**同名但不同指的段落会被收错**。
本项目实测：

| 收错的 | 真相 |
| --- | --- |
| 「路鸣泽」的第24、26、38章 | 是寄生在路明非身上的**魔鬼**，不是叔叔婶婶的儿子 |
| 「龙骨」的第43章 | 是地板的**木龙骨**，不是龙首骨架 |
| 「秘书」的第49章 | 是**恺撒的秘书**，不是那位女秘书 |
| 「俄罗斯」的第29章 | 是**俄罗斯轮盘赌**这个游戏名，不指国家 |

**写法**：读到归属可疑的段落，按原文判断它到底写的是谁，并在条目里显式剔除：

> 另有一处写作「龙骨」的地方指地板下的木龙骨，与这件典藏无关。
> 这一处说的是游戏的名字，指的并不是这个国家。
> 这一处只是比喻，与第15、16章出现的那几架不是同一件东西。

**反过来**：确认是同一个实体的异称（本名与代号、官名与外号），要写进 `aliases`，
但**别名越普通越要当心**——「师兄」「老爹」「校长」「秘书」这类词在别处常指别人，
收作别名会把无关段落错误地链过去。

## 14. 仍然禁止

- 冒号、破折号、「不是……而是……」及同类翻案句
- 商业黑话与模型惯用黑话（「赋能」「闭环」「值得一提的是」「综上所述」）
- 无出处的陈述
- 编造评价（评价分作品内 / 用户提供 / 外部检索三种来源，不许混淆）
- 考据挂空：`sources` 里有、却没有任何节的 `refs` 或 `lead_refs` 指向它

# 二、站点界面

## 整体

- **不同词条各自单独开页面**，不做单文件全塞一页
- 白灰配色：`#fff` 底、`#f8f9fa` 浅灰面、`#eaecf0` 表头、`#a2a9b1` 边框、`#54595d` 次要文字
- **少圆角、无阴影**
- 线框要看得见：主结构 2px，一级标题下划线 3px
- 零外部请求，双击即开

## 顶栏

- **左上角是站点名**，字号要大（1.7rem 以上）
- 站点名其下是作品名
- **不写条目创建时间**

## 位置提示与标签页

- 每页上方有**面包屑**：站点名 < 作品名 < 词条名
- 每页有**条目 / 讨论 / 编辑 / 历史**标签页，当前页高亮，其余置灰
- 讨论、编辑、历史为版式占位，静态站点不含交互

## 首页

- 开头是**作品介绍**（作者、范围、条目数）
- 其下是**几个方框表**做分类跳转（人物 / 地点 / 物品 / 事件），方框内分栏列出条目名

## 词条页：三栏

| 栏 | 内容 |
| --- | --- |
| 左 | **目录**，本页各章节，方框包裹 |
| 中 | 正文 |
| 右 | **信息框**（类型、别称、回目、参与、地点、状态）+ **相关条目**（竖排长标签卡） |

窄屏时右栏上移、左栏下移，退回单栏。

**无目录的页**（例如只有考据一节的 stub）不保留空的左栏，正文不该被它推后。

## 正文排版

- 首行标题用衬线字体，一级标题下 3px 下划线
- 章节标题 2px 下划线
- **原文引用用灰底灰字块**，出处标在块首
- 评价单列一节，按来源分条
- **考据单列一节，默认折叠**，点标题栏展开；条数写在标题栏上（「考据（53 条）」）。
  条目一多，考据块会比正文还长，默认展开会把正文淹掉。
  折叠态下点正文里的上标 `[3]` 要能自动展开（`wiki.css` 用 `:has(.refrow:target)` 做到，
  零脚本）；展开后编号与 `sources` 顺序一致，可逐条回原文核对

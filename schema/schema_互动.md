# 人物互动表 interaction

## 为什么单列一张表

人际关系**不能简化成主客关系**（`A 对 B 做了什么`，B 沦为被动宾语）。要记的是**主体间互动**：
参与各方都是主体，各有自己的动机、理解与处境。同一件事对双方的意义常常不同。

因此本表的核心不是「谁对谁做了什么」，而是**同一互动在各方眼中的样子**。

## 字段

| 字段 | 说明 |
| --- | --- |
| `id` | 稳定标识，形如 `i-0001` |
| `participants` | 参与者，至少两个，须能在人物表里对上。**列全**，不要只写主动方 |
| `chapter` | 发生章号 |
| `kind` | 互动性质：`对话` / `冲突` / `馈赠` / `救助` / `结盟` / `婚配` / `主仆` / `亲缘` / `交易` / `共处` / `其他` |
| `summary` | 发生了什么，**只写事实**，不带任何一方的立场 |
| `perspectives` | **主体间视角**，按参与者分别记：`{"<人名>": {"attitude": "对对方的态度", "intent": "此人的动机", "reading": "此人如何理解这次互动"}}` |
| `asymmetry` | 不对称之处：地位、信息、情感投入、代价承担的差异。**有差异必须写**，没有写 `"无"` |
| `change` | 这次互动改变了什么（关系性质、处境、认知）；没有变化写 `"无"` |
| `note` | 原文依据与其它说明 |

## 铁律

- **不许只记主动方**。`participants` 必须列全，且每个参与者都要有 `perspectives`。
- **不许用「主-客」措辞**。避免「A 帮助了 B」「A 欺骗了 B」这类把一方写成客体的概述；
  改写成事实（`summary`）+ 各方视角（`perspectives`）。
- **不许替人物编动机**。`intent` 与 `reading` 只在原文有依据时填；没有依据就留空字符串，
  并在 `note` 里写「原文未交代动机」。**不许从结果反推动机。**
- **不对称必须显式**。地位/信息/情感不对等是这个表最有价值的部分，不要省略。
- 同一次互动涉及多人时，仍是一条记录，`participants` 列全。

## 与其它表的关系

- 与**时间线**的分工：时间线记**某个实体的属性变化**；本表记**多个主体之间的互动**。
  一次互动若导致某方属性变化，两边都要记，各记各的。
- 与**人物表**的分工：人物表记**单人的静态属性**；本表记**人与人之间发生的事**。

# 审查配置 · v0.2fix

参数作用于**整部作品的运行**，不是每步、每章或每个批次。state 文件续跑时复用，不重新计数。

| mode | max_reviews 默认 | 使用方式 |
| --- | --- | --- |
| economy | 0 | 当前写作 AI 自查 + 脚本，不另起审查 |
| balanced | 1 | 合并稿完成后一次抽样 |
| strict | 2 | 一次抽样；有事实、人称、出处问题才使用第二次 |

可通过 --max-reviews 覆盖次数；--sample-size 默认 4，--context-chars 默认 12000。
字符上限是序列化审查包的大小限制，并非 token 或人民币承诺。
脚本不调用模型；它给 AI 生成有限上下文并记录调用许可。

## 生成、领取、完成

```powershell
python scripts/review_plan.py data/书.entries.json --mode balanced --state data/书.review-state.json -o data/书.review-packet.json
python scripts/review_plan.py data/书.entries.json --state data/书.review-state.json --claim
# 领取成功后，才将 review-packet.json 交给审查 AI；只调用一次
python scripts/review_plan.py data/书.entries.json --state data/书.review-state.json --record-result data/书.review-result.json
```

result 的格式：

```json
{
  "issues": [
    {"entry_id": "e-0001", "kind": "attribution", "sentence": "原句", "fix": "最小改法"}
  ],
  "needs_followup": true
}
```

kind 使用 attribution / voice / evidence / fact / style。
无问题写 issues=[]、needs_followup=false；只有 style 提示时不启用第二轮。
生成包不消耗调用额度；--claim 成功才累计一次，并禁止重复 claim。
未 claim 的 pending 包再次生成时直接复用；已 claim 但未 record 时不能生成新包。
模型失败也算已领取调用，记录失败结果，不通过重建 state 偷跑重试。
要提高额度由用户明确指定；同一 state 的额度不能由续跑命令悄悄提高。

首次领取前可以重建尚未使用的包。文本在包生成后改变，脚本要求重新生成，不把旧包用于新稿。
后续采样优先包含上轮内容问题的条目，再取未审样本；已审无问题的原样文本不重复审。
即使还有额度，上一轮没有内容问题也不自动生成下一轮。
达上限或已通过时输出 stop；不要另起其他审批方绕过。

## 控制上下文

包内只含审查指令、选中的条目、该条目的 sources，以及必要 metadata。
不附全文、全量表、聊天历史、历史审批意见和别批任务。
样本优先覆盖第一人称角色、多人互动、传闻或推测，再覆盖不同实体类型。
可用 --include 指定逗号分隔的高风险 entry id，仍受样本数与字符上限限制。
显式 --include 的条目超限时退出并指出 id；其他放不下的候选在 omitted_candidates 中列出。
需要核查这些条目时先限定具体节与相应证据，或由用户调整上限，不自动截断引文或悄悄超额。

独立审查返回具体句子与最小修法即可，不写审批长报告，不要求润色全库。
局部修复与脚本复检不消耗独立审查次数，不因此另起子代理。
表结构、来源定位、引用编号和页面锚点用脚本检查；语言意义由当前 AI 自查或受限抽样判断。

## 参数例子

```powershell
# 最省钱，不启动独立审查
python scripts/review_plan.py data/书.entries.json --mode economy --state data/书.review-state.json -o data/书.review-packet.json

# 更小的一个审查包
python scripts/review_plan.py data/书.entries.json --mode balanced --sample-size 3 --context-chars 8000 --state data/书.review-state.json -o data/书.review-packet.json

# 用户要求严格模式时：至多两次，每次最多四条
python scripts/review_plan.py data/书.entries.json --mode strict --max-reviews 2 --state data/书.review-state.json -o data/书.review-packet.json
```

state 是工作产物，交付时可以报告实际 calls 数；不要把它与用户 session 或书籍全文提交到仓库。

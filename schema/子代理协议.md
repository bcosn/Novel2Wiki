# v0.3 子代理创建与通信协议

默认不创建子代理。主流程能执行的任务留在当前上下文；存储、校验、合并、图片和书评导入均由程序执行。
只有可独立验收的抽取批次、条目写作批次、受审查台账限制的审查任务才可创建。
创建前写明独立任务理由、负责人、输入范围和唯一输出；并行任务不得拥有同一可替换文档。

## 创建规则

- 使用新的最小上下文，不 fork 父会话，不复制聊天历史、全书或全库。
- 固定角色指令和工具集合；动态任务信息放在后面，复用结果先查 task cache。
- 不允许子代理再创建子代理；默认精简 DSH 配置禁用子代理，需要时单独启用 spawn。
- 每个任务有唯一 ID、冻结指令 hash、输入文件 hash、字符范围、配置和结果位置。
- 数据传递只通过文件和数据库；消息、报告、工具 stdout、报错、重试提示都不得附带整块材料。
- 默认输入总量不超过 12000 字符，调试任务使用 500–1500 字符；任务 manifest 不超过 4000 字符。
- task claim 领取后用 token 提交；租约过期可重领，旧 token 不得提交。失败只回报短原因。

## manifest

```json
{
  "protocol": 1,
  "id": "extract-001",
  "stage": "extract",
  "inputs": [{"path": "绝对文件路径", "sha256": "64位摘要", "offset": 0, "length": 1000}],
  "output": "绝对路径/result.json",
  "rules_hash": "64位固定指令摘要",
  "config": {},
  "reason": "独立批次抽取"
}
```

offset/length 为 UTF-8 解码后的字符范围，不是字节。选取材料用 workspace slice 写入小文件，默认只打印位置、长度、hash。
extract 结果为 `{"documents":{"characters":{"meta":{},"items":[]},...}}`，只提交所属批次的新增记录；冲突拒绝。
append 使用原第四步追加结构；draft 使用原 entries 文档结构；review 使用 issues/needs_followup。
draft 替换已有条目时 config.expected_entries_hash 必须对应当前文档，防止旧任务覆盖新稿。

## 返回

```json
{"id":"extract-001","status":"completed","result_path":"绝对路径/result.json","result_hash":"64位摘要"}
```

主代理只读取任务状态和具体冲突；程序读取完整结果并校验、入库。不再让合并代理重复阅读。
输入、规则、配置变化导致任务缓存失效。文件路径和任务 ID 不作为内容缓存的唯一依据。
协议约束属于执行责任；程序检查元数据与预算，无法保证某个平台没有额外继承历史。

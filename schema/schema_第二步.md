## 第二步：奠基（抽四表）

读原文，先产出四张基础表：人物、地点、物品、种族。第三步在此之上追加。

## 读多少

- 短篇：读全文。
- 长篇：读前 10 章。

## 层级规则（地点、物品、种族共用）

`level` 数字越小范围越大，**0 永远是最大**。

| level | 地点例 | 物品例 | 种族例 |
| --- | --- | --- | --- |
| 0 | 宇宙、天下 | 万物 | 生灵 |
| 1 | 国、省 | 大类（如「首饰」） | 妖族 |
| 2 | 市、府 | 小类（如「玉佩」） | 狐族 |
| 3 | 县、街、宅院 | 具体物件（如「通灵宝玉」） | 九尾狐 |

**具体分级按作品设定**：哪一级放镇、放巷、放庙，由该作品的地理尺度决定，不做跨作品对齐；
深度以够用为准，不必强求每部作品都到同一层。

每个地点/物品记 `parent`（上一级的名称），最顶级 `parent` 留空。

## 人物表 character

| 字段 | 说明 |
| --- | --- |
| `name` | 最常用称呼 |
| `race` | 种族。现实题材一律填 `人类`；网文里的妖、魔、精灵、兽族等按原文写 |
| `importance` | 重要程度，**暂定值**：`main` / `major` / `minor` / `mention`。后期回调，第三步按实际戏份重算 |
| `gender` | `male` / `female` / `unknown` |
| `age` | 年龄。**存首次出现时的值**，语义与 `first_chapter` 对齐。**保留原文精度**：确数填数字（`16`）；区间填区间（`"7-8"`）；约数加约等号（`"≈50"`）。原文完全没提才留空 |
| `age_note` | 年龄依据：原文出处原话 |
| `age_timeline` | 可选。年龄在后续章节的变化点，逐条记 `{"chapter": N, "age": <同 age 写法>, "note": "<原文>"}`。**只记原文明说的**，不推算 |
| `aliases` | 别称、字、号、昵称、他人对其的称呼 |
| `attributes` | 特殊属性（身份、性格、外貌、能力等） |
| `first_chapter` | 首次出现章号 |
| `note` | 其它需要留存的说明 |

## 种族表 race

| 字段 | 说明 |
| --- | --- |
| `name` | 种族名 |
| `level` | 层级，0 为最泛（如「生灵」），越大越具体（如「九尾狐」） |
| `parent` | 上一级种族名，最顶级留空 |
| `traits` | 特征（寿命、能力、形态、习性等） |
| `members` | 所读范围内出现的该种族人物名 |
| `first_chapter` | 首次出现章号 |
| `note` | 其它说明 |

## 地点表 place

`name`、`level`、`parent`、`type`（如 国/省/府/城/街/宅院/园林/房间）、`first_chapter`、`note`。

## 物品表 object

`name`、`level`、`parent`、`type`、`owner`（持有者）、`first_chapter`、`note`。

## 原则

- 每条都要能在原文里找到依据，不编。
- 拿不准的字段留空或写进 `note`，不要猜。
- `importance` 是暂定值，第三步回调；抽取阶段不必纠结。
- `age` 按作品定：**原文明说才填数字**，推断只写进 `age_note`。不同作品的年龄精度因此不同，这是允许的。
- 现实题材作品没有非人种族时，`race` 表可以为空数组，人物 `race` 统一填 `人类`。

# 动态属性表 custom_attribute

## 为什么要这张表

四表给的是**通用核心字段**（`name`/`level`/`parent`/`race`/`gender`/`age`…）。但每部作品都有
自己特有的属性，通用字段装不下：

| 作品类型 | 特有属性例 |
| --- | --- |
| 红楼梦 | 判词、诗号、花名签、诨名、住处 |
| 修仙/玄幻 | 境界、灵根、功法、法宝、血脉 |
| 都市 | 公司、职位、社交账号 |
| 历史 | 官职、封号、谥号 |

这些**不能预先穷举**，否则 schema 会被某部作品绑死。所以单列一张表，**按作品动态添加**。

## 何时添加

- **奠基（第二步）**：只填四表的核心字段。**不要**在这里扩展属性。
- **追加（第四步）**：读到作品特有属性时，**当场定义并记入本表**。这是本表的主要入口。

一部作品第一次遇到某类特有属性时，就在本表新增该属性的定义；后续同类直接复用，
不要每个实体各起一个名字。

## 字段

| 字段 | 说明 |
| --- | --- |
| `name` | 属性名，**作品内的统一叫法**（如「判词」「境界」） |
| `target_kind` | 该属性挂在哪种实体上：`character` / `place` / `object` / `race` |
| `target` | 具体实体名，须能在对应表里对上 |
| `value` | 属性值 |
| `chapter` | 该值出现的章号 |
| `evidence` | 原文依据 |
| `note` | 其它说明 |

## 铁律

- **属性名按作品统一**。同一类属性全篇只用一个名字，不要「判词」和「判语」混用。
- **不许为了填表而编**。原文没有该属性就不记。
- **核心字段不要塞进来**。`age`/`gender`/`race` 这类已有固定位置，不走本表。
- 本表允许**同一属性名对同一实体有多条**（不同章取值不同），此时按 `chapter` 排序即为其时间线。
- 新增属性名时，在本表 `note` 里写一句该属性的定义，便于后续一致使用。

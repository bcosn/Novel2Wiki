# 第五步：撰写条目

把前几步的表变成**可读的百科条目**。一步一章不读，只消费已有产物。

## 条目来源

人物、地点、物品、事件各写条目。范围由前几步决定：

- 短篇：全文产物
- 长篇：已追加到的范围

## 语言要求

**完整规范见 `维基风格规范.md`**，这里只列要点：

- **只陈述事实，不解释不评价。** 编者不替读者解读，解释是读者的工作。
  自检问句是「这句话是原文里的，还是我想出来的」。
- **叙述用现代汉语，不照搬原文腔调。** 原作是文言或半文半白时，叙述要译成现代汉语；
  原文的用词、句法、语气只保留在引文里。**不要把原文句式改一改就当叙述用。**
- **正文引用原文必须标出。** 用了原文的字句就加引号「」；原文整句还要挂注脚编号。
  没加引号的叙述必须是现代汉语，读者要能一眼分清哪些字是原作的。
- **专名不受此限，且不许为躲检查而改写。**
- **不许把长串削到判据以下**（判据是 ≥6 字，不是 ≥10 字）；改法是整句重译，不是削字。
- **代词消歧优先，避免结巴。**
- **首句直陈身份**，交代这是谁/什么、与作品的关系。
- **去掉口语连接词**（便、就、于是、而后）。
- **原文没写的要标明**，用「书中未写明」「原文没有交代」直陈。
- **细节走引用不走正文**，原句放考据节。
- **成稿正文严禁冒号、破折号、「不是……而是……」及同类翻案句**，并清除商业黑话与模型惯用黑话。

## 考据要求

**每条陈述都要能回溯**。条目里的每个事实，在 `sources` 里给出章号与原文引语。
没有出处的陈述不许写。

## 评价字段

`reception` 记他人或读者对这个人/物/事的评价，**分三种来源，不许混淆**：

| 来源 | 写法 | 说明 |
| --- | --- | --- |
| 作品内 | `in_work` | 书中人物的评价，须有原文出处 |
| 用户提供 | `user` | 用户上传的评价材料，须注明来源 |
| 外部检索 | `external` | 联网查到的评论/研究，须给出链接 |

**顺序**：先用用户提供的材料；没有就问用户；用户不提供再联网检索。
**不许自己编评价**，也不许把作品内的评价说成外部评价。

## 条目字段

| 字段 | 说明 |
| --- | --- |
| `id` | 稳定标识，形如 `e-0001` |
| `kind` | `character` / `place` / `object` / `event` |
| `name` | 条目名 |
| `aliases` | 别名，用于跳转重定向 |
| `lead` | 首段。一两句说清这是谁/什么、在故事里的位置 |
| `sections` | 正文，`[{"heading": "...", "body": "..."}]` |
| `sources` | 考据：`[{"chapter": N, "quote": "原文"}]` |
| `reception` | 评价，见上 |
| `links` | 指向其它条目的 `id`，用于跳转 |
| `stub` | 布尔。材料不足时标记为待补，**不要硬凑** |

## 事件条目

事件是**一次发生的事**，与互动表的分工：互动记**关系**，事件记**事情本身**（时间、地点、参与人、经过、后果）。

字段：`id`、`kind`（固定 `event`）、`name`、`chapter`、`participants`、`place`、`lead`、
`sections`、`sources`、`links`。

## 渲染

输出**多页维基式站点**（完整版式见 `维基风格规范.md` 第二节）：

```
index.html            首页：作品介绍 + 分类方框表跳转
<词条名>.html          每个词条单独一页
assets/wiki.css       共用样式
```

要求：

- **不同词条各自单独开页面**，不做单文件全塞一页
- 可跳转：正文里的人名/地名/物名自动指向对应条目，只链两字以上的名字，每个目标只链第一次
- 左上角是**站点名**，其下作品名；**不写条目创建时间**
- 每页有面包屑与「条目 / 讨论 / 编辑 / 历史」标签页
- 词条页**三栏**：左目录、中正文、右信息框与相关条目
- **原文引用用灰底灰字块**，出处标在块首
- 零依赖、零外部请求，双击即可打开
- 不得内嵌任何密钥或外部 API 调用
